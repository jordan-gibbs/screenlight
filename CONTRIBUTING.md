# Contributing

Screenlight does one thing: it puts a soft light around your screen. It's meant to stay that way.

- **Bugs:** open an issue using the template. Include your OS and the steps to reproduce.
- **Platform fixes** (macOS, Linux, odd display setups) are the most useful contributions.
- **New features:** open an issue first and wait for a yes before writing code. Unsolicited feature PRs will be closed.
- **AI-generated PRs** are fine only if you've built and run the result yourself and can explain the change.
- Keep PRs small and focused. No reformatting, dependency bumps or refactors unless you've been asked.

Maintainers may close anything without a detailed explanation. That's not personal; it just keeps the project small.
